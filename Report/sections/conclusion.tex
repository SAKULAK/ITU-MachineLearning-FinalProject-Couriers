A custom Decision Tree and a Feed Forward Neural Network were successfully and correctly implemented and used for predicting Risk in an insurence dataset. A third mehtod involving a combination of classification and regression was implemented to get over the hurdle of an imbalanced dataset. Overall this project was successfull in implementing machine learning methods from scratch and in using them in practice. It showed the need for creative problem-solving with the thrid method and achieved acceptable, however definitely improvable, performance in the final Risk prediction task. 

\subsection{Improvments}
Model performance might be better if other methods to prepare the data, deal with the imabalance in the dataset were used, or perhaps some interaction terms were found in the data. These all could be explored in future works.

\subsubsection{M3 - Ensemble}
After review of the resutls of the Ensemble, the decision to train on just class 1 datapoints might have been the wrong decision. Since the classification layer let a lot of 0 class datapoints into the regression layer and the regression layer had no idea that \texttt{Risk} can equal to zero it predicted larger values, leading to a higher MSE. Therefore, training the regression layer on the entire dataset might be preferable.

\subsection{Procedure}
Before any work being done the dataset was split into two datasets a Training and a Testing set. Any development training was done on the testing set, while the final performance results were taken using the testing set.\\
After the development of M1 and M2 was done and M3 was decided a Random Grid Search with cross validation was performed using sklearn \texttt{RandomizedSerachCV} to find a set of hyperparameters around which an ordinary Grid Search was ran to pinpoint the best parameters.
\subsubsection{Training}
Training was performed on a more balanced dataset, using both undersampling of the datapoints with low Risk and oversampling the higher Risk data points.

\subsubsection{Evaluation}
Models were evaluated using MSE as this is the standard procedure of comparing base model performance for regression. The classification portion of the ensemble method was valuated using Precision to ensure that our regression models get as little zero Risk cases since they were not trained on them.

As seen in~\autoref{tab:classification_report} the classification step of the ensemble performed quite well at filtering the dataset for the regression step. It separated the 0 (\texttt{No Risk}) class with 97\% certainty, meaning that a small amount of class 1 (\texttt{Some Risk}) data points were instantly classified as \texttt{No Risk}. However, overall it did quite a poor job separating the \texttt{Some Risk} class, as almost 50\% of the data that was passed to the regression layer was of the \texttt{No Risk} class, which is impossible for the regression layer to predict correctly because of the decision to only train on datapoints of \texttt{Some Risk} class.

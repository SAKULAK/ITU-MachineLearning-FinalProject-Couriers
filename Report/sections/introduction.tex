This paper aims to explore methods to model the claims risk of insurance policies using various machine learning methods as well as discuss their implementation. It explores and cleans the data, then defines the claims risk based on the information available in the dataset.
\subsection{Machine Learning Methods}
    This paper shows use of the custom implementation of a Feed-Forward Neural Network Regressor and a custom implementation of a Decision Tree Regressor using only Python numerical libraries, e.g. NumPy. Thirdly, an ensemble method is implemented using a combination of classification and regression. The results are lastly compared to the outputs of the models constructed from libraries.

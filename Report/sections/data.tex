\subsection{Data Cleaning}
For data cleaning we decided to take a conservative approach minimally modify the data. We concluded that the data did not have any obvious signs of subverting our assumptions, except for the following:
\begin{enumerate}
    \item Exposure should be in range $(0, 1]$ since the data was collected over one year, so we assume that any value above one is an error, and we set it equal to the max, so 1.
    \item We removed any data points where $VehAge>30$ as this is the cutoff at which Vehicles become classified as historic cars, and are treated differently.
\end{enumerate}
